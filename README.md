# STARBLOOM

Neon arena survival shooter — twin-stick, wave-based, original. Built for [make.fun bounty best-game-01](https://make.fun/bounty/best-game-01).

- 5 enemy types (drone, weaver, brute, spitter, seeker)
- Endless waves with growing budget, combo multiplier up to x3
- Dash with cooldown, magnetic HP pickups, particles, screen shake
- Fully synthesized WebAudio sound — zero external assets, fully offline
- Canvas 1280x720, title screen -> HUD -> game over -> restart, persistent high score

## Run

```bash
node main.ts          # writes /output (game + dossier)
# or open game/index.html directly in a desktop browser
```
